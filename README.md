# ReadySG

ReadySG is a mobile disaster preparedness and response application developed for Singapore. The application focuses on two common environmental risks: flooding and haze.

The project was developed as part of my university Final Project using React Native and Expo.

## Main Features

- Live flood and haze risk information
- Flood and haze emergency guidance
- Preparedness checklist
- Safety quiz with explanations
- Points, levels and achievement badges
- Nearby support locations
- Emergency contact numbers
- Official Singapore information resources
- Offline cached environmental information
- Risk notifications
- Local data storage

## Technologies Used

- React Native
- Expo
- JavaScript
- React Navigation
- AsyncStorage
- Expo Location
- Expo Notifications
- data.gov.sg APIs
- Jest

## Project Structure

- `src/components` - Reusable interface components
- `src/context` - Shared application state
- `src/data` - Checklist, quiz, guidance and support data
- `src/hooks` - Custom React hooks
- `src/navigation` - Application navigation
- `src/screens` - Main application screens
- `src/services` - API, storage, location and notification services
- `src/theme` - Shared design values
- `src/utils` - Helper functions and application logic
- `__tests__` - Automated tests
